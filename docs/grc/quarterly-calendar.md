# Quarterly GRC calendar

| Week | Activity | Owner |
|------|----------|-------|
| Q start | Management objectives review | GRC admin |
| Week 1 | Access review (admin + GRC roles) | IT operations |
| Week 2 | Vendor/subprocessor review | Risk manager |
| Week 3 | Internal control / evidence freshness | Security lead |
| Week 4 | Risk register update | Risk manager |
| Mid-Q | BC/DR tabletop or test | IT operations |
| Mid-Q | Privacy (ROPA, DSR backlog) | Privacy officer |
| End-Q | Internal audit sample | Security lead |
| End-Q | Management review minutes | GRC admin + management approver |

Collectors run daily/weekly via `/api/cron/grc-tick`.
