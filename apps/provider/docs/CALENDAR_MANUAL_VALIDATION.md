# Manual validation — provider calendar (last mile)

Run through on a **small phone** and (if available) a **dense multi-staff day**.

1. **Solo day**: Day view, single column — slots tap through to new booking; booking tap/long-press; empty-day hint when truly empty.
2. **Multi-staff day**: Columns mode — staff headers, horizontal scroll, full-width “now” line; overflow ⋯ on dense cards.
3. **3-day / week**: Strip counts vs grid match canceled preference; swipe navigation; shared now-line overlays.
4. **Status change**: Action sheet / Android sheet — confirm pending disables tap/drag until refresh completes.
5. **Drag reschedule** (day): Ghost follows finger; drop snaps to grid; error alerts localized.
6. **Overlays**: Tap availability / hold / block — menus still work; pull-to-refresh after realtime burst if blocks feel stale.
7. **Preferences**: Open Calendar Preferences — all sections readable in **en** and spot-check **af** (zu/st may still mirror English for long copy).
8. **Low connectivity**: Airplane mode toggle — error state + retry; returning online restores schedule.
9. **i18n**: Switch app language — calendar strings above plus prefs modal keys resolve.
